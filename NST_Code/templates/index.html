Method

Style lives in the statistics of a network's feature maps. Move the statistics, and you move the style — leaving the structure of the photograph intact.

1

Encode

Both images pass through a frozen VGG-19, stopping at relu4_1. A 512×512 photograph becomes a 64×64 grid of 512-dimensional features.

2

Normalise

Each of the 512 content channels is stripped of its own mean and variance — erasing the photograph's style while keeping its layout.

3

Adapt

The style image's mean and standard deviation are applied in their place. No parameters are learned here; it is arithmetic.

4

Decode

A trained decoder inverts the result back into an image. It learned one general skill — features to pixels — so any style works.

AdaIN(x, y) = σ(y) · ( x − μ(x) ) / σ(x) + μ(y) x — content features  ·  y — style features
04

Questions

Is this a pretrained model?

The VGG-19 encoder is pretrained and frozen — it is used only as a fixed feature extractor and never learns. The decoder, which does the actual image generation, was trained for this project.

Does it need retraining for a new style?

No, and that is the point of the method. Earlier fast approaches trained one network per style. Here the styling step reads statistics straight from whatever style image you upload, so an unseen painting works on the first try.

What does style strength actually change?

It interpolates between the photograph's own features and the AdaIN output before decoding. At zero you get a reconstruction of the photograph; at one, full stylisation. It is applied at runtime, so no retraining is involved.

How does blending two styles work?

AdaIN runs once per style, and the resulting feature maps are averaged with your chosen weights before decoding. Because each result shares the same normalised content, averaging them is equivalent to averaging the two styles' statistics.

Which images can be used as a style?

Almost anything — paintings, sketches, photographs, textures. Styles with strong, consistent colour and brushwork tend to read most clearly in the result.

What is the tech stack?

Python, PyTorch and Flask. The model is an encoder–decoder pair with an AdaIN layer between them; the interface is server-rendered with no build step.
